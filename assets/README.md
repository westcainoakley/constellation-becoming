# Assets

This folder is deliberately simple and dependency-free.

- `icons/favicon.svg`: site favicon; replace while keeping the same path to avoid editing every page.
- `images/og-card.png`: 1200 × 630 social preview image referenced by every page.
- `images/archive/`: source screenshots, early poems, art, site copy, research notes and download-cabinet imagery.
- `images/portraits/`: future portraits of Lucy, West or collaboration imagery.
- `images/storyspace/`: future book covers, scene artwork and world-building images.

When replacing any image, update its `alt` text in the relevant HTML page. Avoid placing important text only inside images.
